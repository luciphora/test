# IG onboarding checklist

Mark each: ✅ received · ⚠️ needs fixing (say what) · ❌ missing · ➖ N/A

"Spec" column says what to ask for, so the client request can be specific.

## Tier 1 — blocking (can't post without these)

| Item | Spec to request |
|------|-----------------|
| IG account access | Partner access via Meta Business Portfolio (see access.md) |
| Primary logo | SVG or PDF vector + PNG with transparent background, ≥1000 px wide; light and dark versions |
| Brand colors | Hex codes for primary, secondary, accent, neutrals |
| Profile photo | Square, ≥1080×1080, subject centered (shown as a small circle) |
| Bio + link | Current or desired bio (≤150 chars), link-in-bio destination(s) |
| Starter content | Enough photos/video for the first 2 weeks of posting at the agreed cadence — at least ~10 usable feed images or clips |
| Headshots (personal brands) | 3–5 high-res, varied (smiling, serious, working), ≥1080 px short side |
| Offers & CTAs | What they sell, primary call to action, any active promo/launch dates |
| Approval workflow | Who approves posts, turnaround time, channel for approvals |

## Tier 2 — needed in the first month

| Item | Spec to request |
|------|-----------------|
| Secondary logo / mark | Icon or monogram, SVG + PNG |
| Fonts | Font names; files + license if custom. Otherwise note a free fallback |
| Highlight names + covers | List of highlight categories; covers 1080×1920 with icon centered (or we design them) |
| Testimonials | Screenshots or text, with written permission to post |
| Past top posts | Links or screenshots of 5–10 best performers (or insights export) |
| Lifestyle / BTS photos | Candid, behind-the-scenes, workspace, process |
| Product photos (if selling products) | Clean background + in-use shots, ≥1080 px |
| Raw video / b-roll | Vertical 9:16 where possible, 1080×1920+, original files not screen recordings |
| Voice & tone | 3–5 adjectives, words they use, words to avoid, emoji yes/no |
| Audience | Who the ideal follower/customer is, top problems they solve |
| Content pillars | 3–5 recurring topics |
| Off-limits topics | Anything not to post about or mention |
| Competitors / inspo accounts | 3–5 handles each, and what they like/dislike about them |

## Tier 3 — nice to have

| Item | Spec to request |
|------|-----------------|
| Brand guidelines PDF | Whatever exists |
| Templates | Canva brand kit / Figma file / existing carousel + story templates |
| Press / media mentions | Logos of outlets, links |
| Raw footage archive | Shared folder link |
| Hashtag / keyword list | Any branded or niche tags they already use |
| Analytics baseline | Followers, avg reach, engagement — screenshot of Insights (last 30/90 days) |

## Brand-new account (nothing exists)

Turn the list into a creation plan: for each ❌, record who produces it (client shoot, agency design, AI-assisted) and a due date, instead of requesting it.
