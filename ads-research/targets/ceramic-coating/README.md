# ceramic-coating — category scan

Not a single-page teardown. This target is a **category scan**: every advertiser
selling ceramic coating, pulled page by page, then pooled.

Two populations that must never be averaged together:

- **Service** — a local shop selling the *application* of a coating. Sells an
  appointment. Lead-gen funnel, booking links, local radius.
- **Product** — a DTC brand selling a *bottle*. Sells a cart. Ecommerce funnel,
  volume testing, offer-led creative.

`taxonomy.py` keys `SEGMENT` on this split. Survival numbers are only ever
compared inside a segment.

One snapshot (2026-09-11). State, not delta.
